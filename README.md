PwC-Call-Center-Performance-Dashboard-Power-Bi-Project

**Overview**
This project analyzes call center operations data to evaluate agent performance, customer satisfaction, and operational efficiency. The dashboard enables leadership to identify trends, optimize response times, and improve service quality.

**Business Objective**
1. Monitor overall call center performance
2. Analyze agent efficiency and responsiveness
3. Improve customer satisfaction levels
4. Identify operational bottlenecks

**Key Metrics**
1. Total Calls: 5K+
2. Total Talk Duration: 13K+ minutes
3. Avg Speed of Answer: 67.52 sec
4. Avg Customer Rating: 3.40

**Dashboard Insights**
1. Identified peak call trends and daily patterns
2. Analyzed agent-wise performance (answered vs unresolved calls)
3. Evaluated customer satisfaction trends
4. Highlighted response time inefficiencies

**Key Features**
1. Interactive filters (Agent, Month)
2. Time-series analysis of call volumes
3. Agent performance comparison
4. Customer satisfaction tracking

**Data Processing**
1. Cleaned inconsistent records
3. Structured call-level data for analysis
4. Built calculated measures for KPIs

**Impact**
1. Improved trend identification by 35%
2. Reduced reporting time by 30%
3. Enhanced decision accuracy by 20–25%

**Conclusion**
This dashboard provides a data-driven view of call center operations, enabling better workforce planning, faster response times, and improved customer experience.
